# Alex — Creative Portfolio Website

A modern, responsive, static portfolio website built using **HTML, CSS, and JavaScript**. It showcases creative skills, projects, and contact information with smooth animations and a dark theme.

## 🚀 Features

- Modern dark-themed design
- Animated typing text effect
- Floating particle background
- Smooth scrolling navigation
- Scroll-triggered reveal animations
- Responsive layout for desktop, tablet, and mobile
- Mobile navigation menu
- Skills and project sections
- Contact button using email
- Automatic copyright year
- No external libraries required

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, responsive layout, and animations
- **JavaScript** — Typing effect, particles, navigation, and scroll animations

## 📁 Project Structure

```text
MyPortfolio/
└── index.html
```

All HTML, CSS, and JavaScript code is contained in a single file.

## 💻 How to Run

1. Download or copy the project to your computer.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your browser.

You can also open the file using Visual Studio Code and run it with the Live Server extension.

## 🎨 Customize Your Portfolio

1. Replace `Alex` with your name.
2. Update the About Me section.
3. Add your actual skills and projects.
4. Replace `your-email@example.com` with your email address.
5. Customize the colors in the CSS variables to match your style.
